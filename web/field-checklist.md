# 仓库首次现场验证与记录模板

仓库：________　记录人：________　日期：________

这份模板用于收集模型验证所需资料。倾斜趋势是调查线索，现场检查记录允许原因未知。

## 1. 安装与点位

每个传感器填写：设备编号、图上位置、实际安装位置、货架高度、安装高度、安装日期（未知可留空）、X/Y轴正方向、相对于布局图的方向、预期心跳周期。

附整体与安装近照。轴向确认时标出X/Y正方向，并记录依据、确认日期和确认人。

## 2. 结构关系

货架尺寸、支脚间距、锚固方式、横梁与连接件、相邻货架是否连接、地坪接缝与构造。

区分“看到的连接”“依据图纸确认的连接”和“推测的连接”。空间相邻不自动代表结构连接。

说明基准稳定性的依据：________

测量方法、仪器及精度：________

|---|---|---|---|---|---|

之后在相同测点、相同基准下复测，保留原始结果及误差说明。仓库布局图的百分比坐标不能替代现场距离测量。

## 4. 历史变化

记录载荷重新分布、货架调整、碰撞、锚固维修、传感器更换、重新安装或校准的时间、位置和依据。没有资料时写“未知”，不要补写推断日期。

## 5. 异常检查与跟踪

检查日期、检查人、位置：________

采取措施：________

原因程度：尚不清楚 / 怀疑 / 经测量或检查确认

原因与证据（照片、测量文件编号）：________

后续复测日期、责任人、处理状态：________

照片、PDF、UTF-8 CSV/TXT可以附到网站的一条检查记录。确认原因不自动关闭异常；后续低于筛选条件也不自动表示恢复。

## 6. 客户现场校准后再决定

沉降量反推模型、工程关注门槛、温度校正方法、误报与漏报评估、检查责任分工及数据对接方式。

模拟案例与真实检查分开保存，不作为验证结果。
